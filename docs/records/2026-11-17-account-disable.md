# AUTH-03-01 本地账号停用验收

2026-11-17，在 `dev` 基线 `7c6fde5` 上实现 SQLite v8 及 `radishchat account disable <用户 ID>`。停用在一个事务内变更账号状态并撤销会话、恢复码、所属 Bot 凭据和安装，以及由该账号发起的待审批安装。现有真人接口在数据操作时重新核对会话，保留成员关系和历史。[实施条目](../topics/identity.md#auth-03-01) · [停用命令](../../deploy/README.md#local-account-disable)

本机为 macOS 27.0.1 arm64、Go 1.26.3。Go 测试使用隔离数据库、合成账号和回环 HTTP，OIDC 使用合成发行方。实际 Web 复验使用本轮 Go 二进制与 `radishchat:p2-bot-reply-8dd3503` 的 Web 静态文件，Playwright CLI 0.1.22 驱动两个独立 Chromium 会话。候选服务仅绑定回环地址，CLI 从第二个进程访问同一测试数据库。[Web 静态文件来源](2026-11-15-bot-command-replies.md)

| 检查 | 实际结果 |
| --- | --- |
| 两个 Web 会话及 CLI | 同一合成账号分别在桌面和 390 × 844 视口登录，两边均打开群并显示原消息。应用运行中对目标连续执行两次 `account disable`，目标的三条会话记录均删除，其他成员的会话保留。两边都返回登录页，重用原密码显示通用登录错误。 |
| 在途写入与空闲 SSE | 把发送请求停在读取正文，待停用提交后再放行，返回 `401` 且历史没有新增。第二个 Cookie 无法读取历史或重连 SSE。已有空闲流在定时检查时干净关闭，未再发送同步提示。重启实例后旧 Cookie 和旧密码仍被拒绝。 |
| Bot 与聊天授权 | 被停用账号的 Bot 身份、拉取和回复请求均返回 `401`，其安装、未交付事件和去重摘要清除。尝试安装其 Bot 或批准其发起的旧待审批请求返回 `404`。原真人消息、Bot 回复和成员关系保留。其他成员仍可发送消息，其他所有者的生效 Bot 仍可接收并回复。 |
| 失败回滚及入口约束 | 在删除安装时注入失败，状态、会话、恢复码和 Bot 凭据及安装整体保留。CLI 拒绝不存在的数据库、旧版本库及外部账号。签发会话时拒绝失效的账号状态和已被替换的密码散列。合成 OIDC 对可用账号仍可登录，对停用状态拒绝签发会话。 |
| 迁移与快照 | 空库初始化为 v8。从 v7 迁移时注入索引冲突，数据库仍为 v7，账号状态列和恢复码表均未留存。移除冲突后迁移成功，既有账号、密码散列、外部身份关联及会话保留。v8 CLI 备份与恢复保留待恢复和停用状态，清除副本中的恢复码和旧会话。 |
| 工程检查 | 服务端构建、`go test -mod=readonly -count=1 -race ./...`、`go vet -mod=readonly ./...`、`python3 scripts/check-repo.py` 和 `git diff --check` 通过。 |

首次定向测试捕获了空闲 SSE 关闭时的 `unexpected EOF`。发送成功后清除上一次写入所设的截止时间，复验确认流正常结束。临时服务和浏览器已关闭，合成数据库及测试配置已清理。
