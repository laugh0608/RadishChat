# P1 Web 发送恢复与群成员撤权验收

2026-11-15，[WEB-01-02](../topics/clients.md#web-01-02) 通过单项验收。以 `d82ba04` 为源码基线，叠加本轮改动。在 macOS 27.0.1 arm64 上用 Go 1.26.3、Node.js 24.16.0 构建。测试使用回环 HTTP、临时 SQLite、合成账号和 Playwright 驱动的 Chromium。

| 检查 | 实际结果 |
| --- | --- |
| 发送与重试 | 在首次发送落库后丢弃 `201` 响应。页面保留草稿并显示重试入口。重试沿用原 `requestId`，返回 `200` 和原消息，页面仅显示一条。 |
| 断线与历史分页 | 初始加载最近 50 条。断网时写入 105 条，恢复时暂缓递交首个增量页，同时前翻旧历史并继续写入。恢复后比对页面上全部 170 条的内容及顺序，无遗漏或重复。 |
| 撤权和迟到确认 | 打开群成员与预览，发出一条已落库但确认被暂扣的消息，再由群主移除该浏览器登录的成员账号。会话入口、原页面、成员面板、预览和草稿清除。该账号仍能在私聊收消息。加回后释放旧确认，群聊只显示新授权范围内的消息。 |
| 快速重入 | 断网期间移出并重新加入，恢复后只显示本次加入后的消息。另在历史边界一致时暂停旧成员资格的消息请求，列表返回新标识后自动重载会话，旧草稿和预览被清除。窄屏自愿退出即时退回列表，创建新群也能进入正确会话。 |
| 服务端授权与迁移 | Go 测试确认历史边界相同的两次成员资格有不同标识，旧标识的成员、历史、发送和退出请求返回 `404`。固定 v1 样本的隔离副本从 v1 升至 v3，历史下限、完整性及外键校验通过，成员资格标识在重启后保持。v2 回填故障注入后保留原表与历史边界，解除故障后升级通过。 |
| 工程检查 | Go 构建、`go test -mod=readonly -count=1 -race ./...`、`go vet -mod=readonly ./...`、Web 生产构建、`python3 scripts/check-repo.py` 及 `git diff --check` 均通过。 |

候选镜像及目标 HTTPS 环境由 [OPS-01-03](../topics/deployment.md#ops-01-03) 验收。独立主机名间账号、会话和草稿隔离由 [WEB-01-03](../topics/clients.md#web-01-03) 接续。
