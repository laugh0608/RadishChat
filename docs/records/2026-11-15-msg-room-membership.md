# P1 私聊唯一性和成员操作验收

2026-11-15，[MSG-01-01](../topics/messaging.md#msg-01-01) 通过单项验收。使用 `abe30b9` 的 Go 服务和本轮回归用例，在 macOS 27.0.1 arm64、Go 1.26.3 上，通过真实回环 HTTP、隔离 SQLite 和合成本地账号验证。

| 检查 | 实际结果 |
| --- | --- |
| 并行创建私聊 | 两个账号并行调用 `POST /rooms/direct`，返回同一会话 ID。各自的列表只有一个私聊，成员列表只有两人。私聊双方无法通过群成员接口添加、移除或退出。并行测试在竞态检测下重复五次通过。 |
| 群主和普通成员 | 群主按完整用户名添加，用户名沿用去除首尾空白和小写归一化，前缀匹配被拒绝。群主使用成员列表中的 ID 移除指定成员。普通成员可退出、不能管理成员，群主不能退出或移除自己。重复添加返回 `409`，移除不存在的成员返回 `404`。 |
| 成员资格 | 加入后可列出群、查看成员和发送消息。未加入、主动退出及被移出时，群从列表消失，成员、历史、增量和发送接口返回 `404`。主动退出后可重新被群主加入，被移出后本地登录会话仍有效。 |
| 实例隔离 | 独立实例使用同名、同数字 ID 的合成账号。将其会话 Cookie 随请求发到本实例时，房间列表、成员、历史及写入接口返回 `401`。 |

沿用现有房间事务、SQLite 配对唯一约束和成员授权。Go 全量竞态测试、`go vet -mod=readonly ./...`、Go 构建、`python3 scripts/check-repo.py` 及 `git diff --check` 通过。

群历史按本次加入点授权由 [MSG-01-02](../topics/messaging.md#msg-01-02) 与 SQLite 迁移联合验收。撤权后打开页面的清理由 [WEB-01-02](../topics/clients.md#web-01-02) 覆盖，独立主机名的浏览器实例切换由 [WEB-01-03](../topics/clients.md#web-01-03) 验收。
