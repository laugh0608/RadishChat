# OPS-02-01 维护权限与持久审计验收

2026-11-17，在 `dev` 基线 `2d20769` 上实现 SQLite v9 和只读 `radishchat ops audit`。停用、恢复码签发或重签及解除停用与审计在同一事务提交。维护权限沿用部署侧的数据卷访问权，审计记录维护来源，个人归因依赖部署环境。[实施条目](../topics/deployment.md#ops-02-01) · [查询与分页](../../deploy/README.md#maintenance-audit)

环境为 macOS arm64、Go 1.26.3。用本轮原生 Go 候选二进制、回环 HTTP、独立数据库和合成账号演练实际 CLI。现有 Go HTTPS 反代与会话用例一并复跑。

| 检查 | 实际结果 |
| --- | --- |
| 查询与授权 | 实际 CLI 返回字段受限的 JSON 数组，按编号降序，使用 `--before` 翻页无重复。非法页大小和游标、缺失库、旧版本库及宿主账号无读权限的库均被拒绝。带群主或普通成员 Cookie 访问 HTTP 审计路径返回 `404`。 |
| 状态变更和回滚 | 三种操作记录维护来源、目标、时间和结果，重复停用记录 `already_disabled`。注入审计失败后，旧会话、恢复码和已授权 Bot 状态整体回滚。失败签发与解除停用未交付恢复码，撤销故障后可重试。 |
| 诊断与准入 | 检查候选服务日志和 CLI 审计及诊断输出，未发现合成消息、密码、Cookie、邀请码或恢复码。切换实例邀请码后旧码返回 `403`，新码可注册。关闭注册后邀请码也被拒绝，既有账号仍可登录。 |
| SQLite 与快照 | v8 迁移注入索引冲突时仍为 v8，移除冲突后升至 v9，已停用账号、会话及恢复码保留，审计从升级后记录。快照保留审计和原操作时间，清除旧会话及恢复码。超出 90 天的测试记录在源库与恢复库均从查询窗口排除。到期记录的清理归 OPS-02-03。 |
| 工程检查 | Go 构建、定向账号和准入测试、全量 `go test -mod=readonly -count=1 -race ./...`、`go vet -mod=readonly ./...`、仓库检查和差异检查通过。 |
