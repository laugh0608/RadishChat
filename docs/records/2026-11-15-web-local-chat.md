# P1 Web 本地准入与聊天主路径验收

2026-11-15，[WEB-01-01](../topics/clients.md#web-01-01) 通过单项验收。以 `c853e92` 为源码基线，叠加本轮 Web 改动。在 macOS 27.0.1 arm64 上用 Go 1.26.3、Node.js 24.16.0 构建。Playwright 使用桌面 Chromium（1366 × 900）和独立窄屏浏览器会话（390 × 844），访问同一个回环 HTTP 实例和临时 SQLite。各阶段通过重启 Go 进程使用 `on`、`invite`、`off` 三种注册配置。

| 检查 | 实际结果 |
| --- | --- |
| 受控与邀请码准入 | `on` 模式下桌面可直接注册。切换到 `invite` 后，已经打开的注册表单收到 `403`，重新读取实例能力并显示邀请码字段，保留已填用户名和密码。错误码被拒绝，有效码在桌面和窄屏均可注册。两个账号退出后均可使用本地账号重新登录。 |
| 私聊与小群 | 桌面账号创建私聊并发送，窄屏账号打开并回复。窄屏从会话返回列表后建群并邀请桌面账号，成员列表显示预期成员。两端在同一小群中互发并看到对方的 Markdown 消息。 |
| 普通会话隐私提示 | 桌面和窄屏的私聊和群聊均在会话顶部说明服务端处理并保存正文，以及数据库或备份访问者可读取。两种视口下会话页面无横向溢出。 |
| 关闭注册后的恢复 | 服务使用同一临时库切换到 `off`。已经打开的注册页提交有效邀请码仍返回 `403`，表单随即回到登录并隐藏注册入口。桌面和窄屏已有账号均在退出时重新取得准入配置，无需手动刷新即可重新登录，打开原群并读到双方已发送的消息。 |
| 工程检查 | Go 构建、`go test -mod=readonly -count=1 -race ./...`、`go vet -mod=readonly ./...`、Web 离线依赖安装与生产构建、`python3 scripts/check-repo.py` 和 `git diff --check` 均通过。 |

发送恢复、撤权和重新加入由 [WEB-01-02](../topics/clients.md#web-01-02) 接续。独立 HTTPS 主机名和候选部署分别由 [WEB-01-03](../topics/clients.md#web-01-03) 和 [OPS-01-03](../topics/deployment.md#ops-01-03) 验收。
