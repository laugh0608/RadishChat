## 实测结果

双实例使用 Caddy 2.11.4，仅在回环地址发布端口，依次验证证书链和两个测试主机名。Playwright CLI 0.1.24 驱动 Chromium，使用隔离的浏览器状态，按进程限定测试站点的证书公钥。桌面视口为 1280 × 800，窄屏为 390 × 844。账号、邀请码、消息和数据库均为合成材料。

| 场景 | 实测结果 |
| --- | --- |
| 安装、准入和会话 | 空数据目录启动成功，默认注册关闭。双实例经 HTTPS 的健康检查通过，缺失和无效邀请码被拒绝，合成账号可注册。Cookie 具有 `Secure`、`HttpOnly` 和 `SameSite=Lax`。关闭外部登录时，发起和回调接口返回 404。恢复后关闭注册，既有账号仍可登录。 |
| 私聊与 Markdown | 桌面和窄屏用户双向收发。预览与收方渲染显示加粗、列表和代码块，外部图片只显示占位，未知协议链接不可点击。界面展示服务器处理和保存正文的隐私说明。 |
| 发送确认、补拉与历史 | 模拟写入已完成但客户端未收到确认。重试使用同一 `requestId` 并返回原消息，变更正文的重试被拒绝。窄屏端断网后按顺序补齐 105 条消息，无重复，收到恢复途中追加的消息。新标签页可分两页向前加载历史。 |
| 群历史与撤权 | 成员只能看到本次加入后产生的消息。被移除后会话和编辑区消失，历史接口返回 404。重新加入后旧消息和旧草稿均不可见，后续消息可收取。 |
| 实例隔离 | 同一标签页在两个 HTTPS 主机名往返。两个实例使用相同用户名和数字会话 ID，账号、会话列表与草稿仍隔离。B 拒绝 A 的密码，退出 B 清除其草稿，A 会话保持可用。 |
| 干净库备份与恢复 | 在源卷停服后以只读方式备份。原卷重启后原会话可用。将备份恢复到新命名卷，拒绝重复覆盖。恢复后旧会话访问账号、会话列表、成员、历史及 SSE 均返回 401。重新登录后读回相同的账号、成员和消息，实时连接仅发送通用同步信号。卷目录和数据库归 UID `10001`，模式分别为 `0700` 和 `0600`，其他非特权 UID 无权读取。抽查的密码、邀请码、会话值和消息正文未出现在应用或反代日志中。 |
| 固定 v1 样本 | 原样本 SHA-256 为 `659c7c324189616b36af07b098337103b1a4ad21d3314824ef93bd75d2469129`，复验后比对一致。在隔离副本阻止成员回填，启动失败并回滚至 v1，成员及消息保留。从升级前备份恢复 v1，用与基线 SHA-256 相同的预览二进制验证可登录并读取原群历史。另一副本正常升至 v3，完整性和外键检查通过，原私聊可读，旧群正文按加入边界隐藏，新群消息在重启后正常读写。 |
