# Bot 开放接口

让第三方在明确授权的会话中添加自动化。Bot 使用独立身份、权限和生命周期。

阶段验收目标：一个第三方按公开文档实现并安装 Bot，群成员可以查看它的访问范围，群主撤销后停止新访问。

本页维护各子专题的设计与执行状态。跨专题顺序见[整体规划](../planning/project-plan.md)，近期优先级见[当前状态](../status/current.md)。

<a id="bot-01"></a>

## BOT-01 Bot 身份、安装与授权

- 阶段与状态：P2。规划，待开始。
- 范围：设计实例内 Bot 身份、所有权、独立凭据、轮换、可见权限与移除。协作群显式安装，默认最小权限。
- 依赖与基础：依赖 AUTH-01、MSG-01。与 [LOCK-01](privacy.md#lock-01) 核对加密房间边界。
- 验收：普通成员不能安装或扩大权限。凭据只在授权范围生效。移除和轮换后旧凭据失效。

<a id="bot-02"></a>

## BOT-02 事件、命令和示例 Bot

- 阶段与状态：P2。规划，待开始。
- 范围：明确事件版本、重试语义、速率限制、命令范围和自托管接入。用部署通知或显式命令作参考案例。
- 依赖与基础：依赖 BOT-01、MSG-02。Webhook 或轮询先评估交付成本、可靠性和运维影响。
- 验收：Bot 仅获得授权事件，掉线、重试及撤销可验证。独立开发者可按接口文档编写第二个 Bot。
